# AI assistance

Claude (Anthropic) and Codex (OpenAI) assisted with manuscript organisation, drafting, language editing, translation, and Python coding for analysis and figure preparation. The manuscript's Methods describe analytical coding assistance and verification against saved outputs. The authors retain responsibility for the research and publication.

The current research figures are generated with plotting code from analysis outputs and geographic inputs, with schematic panels for the design. This release contains no AI-generated replacement observations or image-derived research measurements. Model version details were not consistently recorded in the historical workflow and are not invented here.

This code-only packaging step adds documentation, integrity checking and a working-copy configuration helper. It does not rerun experiments, alter their frozen code or delete unfavourable results.
