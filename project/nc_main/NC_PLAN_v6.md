## 0. 动机、期刊与研究问题

**动机**
- 地图模型迁移到一个没有本地标签的新地区时，现成的卫星基础模型嵌入（AlphaEarth，AE）可以免费使用，用起来和传统的 Sentinel-2 统计特征（S2）一样容易。
- 真正昂贵的是实地采集的本地标签。机构需要知道：嵌入能替我省掉多少标签？我还需不需要采？

**目标期刊与普遍意义**
- 投稿 Nature Communications。
- 要回答的普遍问题是：在基础模型时代，全球地表制图还需要多少本地实地数据？
- 这个答案影响数据稀缺地区的监测预算，也给出评价基础模型的一种实际货币，即省掉的本地标签数。

**研究问题**

| | 问题 | 回答方式 |
|---|---|---|
| RQ1 价值 | 迁移后，免费的嵌入替你省掉多少本地标签？ | 零标签的 AE 与常规做法"S2 + k 个本地随机标签"正面比较 |
| RQ2 边界与规则 | 什么情况下嵌入替代不了本地标签？能否用少量标签提前判断？ | 看用上 AE 后 200 个本地标签的增益，如何随"50 个本地标签测得的零标签迁移精度"变化 |

**确认性假设**
- **H1（RQ1）**：在多数目标地区，零标签的 AE 胜过"S2 + 200 个本地随机标签"。
- **H2（RQ2）**：用上 AE 后，200 个本地标签的增益随零标签迁移精度 M 上升而下降。

H1 与 H2 用 Holm 校正，族错误率 0.025（单侧）。其余量都只报估计值。

**术语**

| 术语 | 含义 |
|---|---|
| 任务族 | LCZ（城市形态，So2Sat LCZ42，17 类）、LUCAS（土地覆盖，7 类）。作物为锚点任务，不进入确认性检验 |
| Z0、RT_k | 只用源池训练；源池加目标域 k 个随机标签 |
| Δ_V(A → B) | 模型 B 相对参照模型 A 的稳健版"同 OA 下的 BA"差（第 3 节） |
| e(k) | Δ_V(S2 的 RT_k → AE 的 Z0)：零标签 AE 相对"S2 + k 个标签"的优势；d = e(200) |
| L_saved | AE 省掉的标签数：保序回归后的 e(k) 首次 ≤ 0 时的 k |
| g(k) | Δ_V(AE 的 Z0 → AE 的 RT_k)：用上 AE 后 k 个本地标签的增益 |
| M | AE 的 Z0 在 50 个本地候选样本（抽样顺序第 201–250 个）上的总体精度（%） |

## 2. 划分、抽样与训练（复用试点代码，种子前缀为 nc_main_v1）

**种子**
- 种子整数 = int(md5(字符串.encode('utf-8')).hexdigest(), 16) mod 2^31。
- 占位符：{任务} ∈ {lcz, lucas}；{域} 取样本表原值、不改大小写：LCZ 为 city 列（小写，如 beijing），LUCAS 为 nuts0 列（两位大写，如 DE），与试点相同；{特征} ∈ {ae, s2}；{臂} ∈ {Z0, RT50, …, RT1600}；{r} ∈ {0, 1, 2}，Z0 固定写 r0。
- 种子字符串：
  - 划分：`nc_main_v1_{任务}_split_{域}`
  - 抽样顺序：`nc_main_v1_{任务}_srs_{域}_r{r}`
  - 拟合：`nc_main_v1_{任务}_fit_{域}_{学习器}_{特征}_{臂}_r{r}`
  - bootstrap：`nc_main_v1_boot_M1`（只用于第 4 节 M₁ 的区间）
- 随机数生成器：`nc_common.rng_of(种子字符串)`，即 numpy.random.default_rng(种子整数)；每个种子字符串只建一个生成器。

**为什么只用空间分块**
- 应用场景是在新地区做覆盖全区的地图。几百个本地标签散在一个城市或国家里，地图上绝大多数位置离最近的标签都有数公里到数十公里。分块测试使测试样本离训练标签至少 500 m（LCZ）或 1 km（LUCAS），模拟的正是这种情形。
- 空间随机划分只有在两个条件下才有意义：测试样本是对地图的概率抽样，且不是训练样本的近似重复（Wadoux et al. 2021, Ecological Modelling）。
  - LCZ 不满足：So2Sat 的样本块从人工勾画的多边形中切出，中心间距 100 m、彼此重叠。随机划分测到的主要是对多边形的记忆。同一模型在随机划分、空间分块、新城市上的 OA 分别为 83%、77%、51%（Zhu et al. 2022, RSE）。
  - LUCAS 满足，但其点距约 4 km，随机划分与分块划分几乎相同。
- 因此不另设随机划分，只在方法中说明上述理由。

**划分**：与试点相同，复用 `nc_split.split_domain`。
- 网格与缓冲：
  - LCZ：2 km 网格，原点 0；缓冲 500 m。
  - LUCAS：EPSG:3035 中 10 km 网格，原点平移 5 km；缓冲 1 km。
- 坐标用 numpy.round 取整到 1 m；测试网格数为 Python round(0.3 × 网格数)。
- 候选 = 不在测试网格内、且到最近测试样本的距离不小于缓冲距离的样本。

**抽样顺序**
- 候选按 sid 升序，用 `rng.permutation` 打乱，r = 0、1、2。
- 剔除缺失后保持相对次序。
- RT_k 取前 k 个，k ∈ {50, 100, 200, 400, 800, 1,600}，只取 k ≤ 剔除后候选数的档。
- 本地 LCZ 城最多到 400；LUCAS 大国可到 1,600。

**训练**
- 学习器：LightGBM，参数与 RSE、试点相同，num_class 为 17 或 7。
- 特征：AE、S2 各自独立训练。
- 臂：Z0；RT_k，每档 3 次抽样。
- 权重：类别权重为源池类别频率的倒数（RSE 的 `class_weights_from`）。源样本取类别权重，目标样本取 50 × 类别权重。
- 行序：源池样本按 (域名, sid) 升序在前，目标样本按抽样顺序在后。
- 线程：每次拟合 2 线程；启动时断言库版本与 RSE 相同。

**附录学习器**（只报估计值）
- 范围：AE、S2 的 Z0 与 RT200，RT200 做 3 次抽样，与 LightGBM 共用同一批样本。
- 随机森林：`RandomForestClassifier(n_estimators=500, max_features='sqrt', min_samples_leaf=1, bootstrap=True, class_weight=None, random_state=拟合种子, n_jobs=2)`，`sample_weight = w`。缺失值用训练集中位数填补，中位数不加权。参数与 RSE 相同。
- 逻辑回归：
  - 缺失值用训练集中位数填补；用训练集不加权的均值与标准差标准化，标准差加 1e-6；
  - `LogisticRegression(C=1e-3, max_iter=1000, tol=1e-4)`，`sample_weight = w / mean(w)`。标准化与权重归一化与 RSE `multilearner_G` 相同；RSE 的 C 由留国家组交叉验证选取（44 次运行均为 1e-3 或 3e-4），此处固定 C = 1e-3，不调参。
- 概率：预测概率按 `model.classes_` 填入全部类别列，缺席的类概率为 0。
- 种子：拟合种子中的 {学习器} ∈ {lgb, rf, lr}，即 `nc_main_v1_{任务}_fit_{域}_{学习器}_{特征}_{臂}_r{r}`；LightGBM 写 lgb。

**保存**
- 每次拟合保存测试集概率。
- AE 的 Z0 另外保存第 r = 0 次抽样顺序第 201–250 个候选样本的预测，用于计算 M。

**失败处理**：用同一种子重试一次；仍失败则剔除该域并报告，不改代码重跑。

**规模**：LightGBM 约 1,300 次，随机森林、逻辑回归各约 380 次。单进程约 30–40 小时（随机森林每次 90–270 s），并行时约 1 天。

## 3. 度量

**τ 族与 BA**：与 RSE 相同。
- ℓ = log P − τ·log π̂，τ = −2…2，步长 0.05；π̂ 为测试集平均预测概率，不用标签。
- BA 为 BA 类别召回率的平均。

**Δ_V(A → B)（稳健版同 OA 下的 BA）**
- 包络：BA⁺_X(o) 为模型 X 的 τ 路径上 OA ≥ o − 1e-9 的所有点中的最高 BA。路径包括 81 个顶点，以及相邻顶点间线性插值所得、OA 恰为 o 的点。
- 窗口：锚点 m = min(OA_A(τ=0), OA_B(τ=0))；网格 o_j = m + round(−4 + 0.1·j, 1)，j = 0…40。
- 定义：Δ_V = 41 个格点上 BA⁺_B − BA⁺_A 的平均。
- 与 RSE 原指标的区别：原指标只取 OA 恰好等于 o 的点；当 B 整体向右上方移动时，原指标只能读到 B 被支配的尾部。在作物 9 国上，两者对 Δ_R 与两特征平均 Δ_L 的国家值相差 ≤ 0.10 pp。
- 正式实现：`nc_main/nc_metrics.py` 的 `delta_v`（独立编写，只依赖 numpy）。参考实现：`design_calc/metrics.py` 的 `env_fd`，只用于单元测试 1 的比对。

**域级量**：均先在每次抽样内配对计算，再对 3 次抽样取平均。
- e(k) = Δ_V(S2 的 RT_k → AE 的 Z0)；e(0) = Δ_V(S2 的 Z0 → AE 的 Z0)；d = e(200)。
- g(k) = Δ_V(AE 的 Z0 → AE 的 RT_k)。
- M：AE 的 Z0 在 τ = 0（argmax，并列取首个）时，对剔除缺失后第 r = 0 次抽样顺序第 201–250 个候选样本的正确率（%）。
  - 这 50 个样本不进入 r = 0 的 RT50–RT200，所以 M 的抽样误差与 g(200) 的 r = 0 分量不共用训练样本。
  - M 是实践者先花 50 个标签就能看到的量，不做测量误差校正。

**L_saved**（每个域）
- 保序回归：在 K = {0} ∪ {该域实际拟合的预算档}（k ≤ 剔除后候选数；作物为 {0, 50, 100, 200, 400}）上，k_max = max K；ê = −pav(−e)，即单调不增的等权保序回归（`analyze_confirm.pav`）。
- 取值：取首个 ê(k_j) ≤ 0 的格点，在它与前一格点之间线性插值。
- 边界：ê(0) ≤ 0 时，L_saved = 0；ê(k_max) > 0 时，记为"> k_max"。
- 汇总：对每个 k，报告 ê(k) > 0 的域所占比例，即 L_saved > k 的域的比例。只在有该 k 的域上计算，并注明域数。

**单元测试**（冻结代码前必须通过）
1. 正式实现的 Δ_V 在 RSE 作物与试点概率上，与参考实现 `V_min` 逐值之差 ≤ 1e-9。
2. Δ(A → B) = −Δ(B → A)，误差 ≤ 1e-12。
3. 合成前沿上移 (0, +δ) 时，Δ_V = δ。

## 4. 检验与判定（写死）

**确认性分析集**：LCZ 与 LUCAS 的全部合格目标域，47 个（第 1 节）。

| 假设 | 检验 |
|---|---|
| H1：P(d > 0) > 1/2 | 两族合并，精确二项单侧检验 |
| H2：β < 0，g_i(200) = a + γ·[族 = LUCAS] + β·M_i + ε | OLS，HC3 稳健标准误，单侧 t，自由度 n − 3 |

**Holm 校正**：p 值较小者在 0.0125 下检验；它被拒绝后，另一个在 0.025 下检验。

**主张措辞**
- H1 被拒绝：写"在多数目标地区，零标签的 AE 胜过 S2 加 200 个本地标签"，并附 L_saved 的分布。
- H2 被拒绝：写预算规则："先用 50 个本地标签测零标签迁移精度。高于 M₁ 时，再采 200 个标签预期提升不足 1 pp；低于 M₁ 时，应采标签。"
  - 每族的 M₁ = 拟合的 g(200) 降到 1 pp 处的 M：LCZ 为 (1 − â)/β̂，LUCAS 为 (1 − â − γ̂)/β̂。
  - 区间：95% 区间，按族分层的域级 bootstrap 2,000 次，每次重拟合同一 OLS。种子 `nc_main_v1_boot_M1`；每族的域按名称升序，同一生成器先 LCZ、后 LUCAS 各调用一次 `rng.integers(0, n_族, size=(2000, n_族))`。
  - β̂_b ≥ 0 的重抽样不计入，并报告其比例 q。q ≤ 2.5% 时，在其余重抽样上用 `analyze_confirm.q_interval(·, level=0.95)`（逆经验分布，不插值）；q > 2.5% 时不报区间，写"无界"。
  - M₁ 落在该族观测到的 M 的 [最小, 最大] 之外时，注明"外推"。
- 未被拒绝的假设只报告估计值，不写成结论。

**只报估计值**
- d 的均值与中位数，分族及合并；
- e(k)、g(k) 的剂量曲线；
- L_saved 的分布；
- 附录：随机森林、逻辑回归的 d 与 g(200)，以及 d > 0 的域所占比例。H1 被拒绝且两者 d > 0 的比例（点估计）都 > 1/2 时，写"三种学习器方向一致"，否则写"结论限于 LightGBM"；
- 作物锚点。

## 6. 功效（依据：17 个已有域按 Δ_V 的描述性重算，见 `design_calc/`）

**已有域的情况**
- d > 0 的域为 12/17，中位数 +4.2。
- g(200) 与零标签 AE 的 OA 的 Spearman 相关为 −0.60；去掉迁移崩溃的 RO、PT 后为 −0.44。

**模拟设定**（`design_calc/power_sim.py`，1 万次）：从已有域有放回重抽 47 个（LCZ 29、LUCAS 18）；M 取 50 个标签的二项观测值；Holm 校正。

| 情形 | H1 | H2 |
|---|---|---|
| 确认性域中没有迁移崩溃的地区（试点的 LCZ、LUCAS 域属于这种情形） | 0.99 | 0.39 |
| 有 RO、PT 这类崩溃地区 | 0.81 | 0.98 |
| 没有崩溃地区，且 AE 胜出的真实比例只有 0.65 | 0.42 | 0.27 |

两个假设互补：迁移崩溃的地区少、且 AE 胜出的比例与已有域相近（约 0.8）时，H1 几乎必定成立；崩溃地区多时，H2 几乎必定成立。
