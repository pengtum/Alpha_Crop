## 0. 问题、框架与术语

**背景**
- 地图模型迁移到一个没有本地标签的新地区时，机构可以零成本地使用现成的卫星嵌入，例如 AlphaEarth（AE）。
- 剩下的决定是要不要在当地采标签、采多少、怎么采。实地标签很贵。

**三个问题**

| | 问题 | 怎么回答 |
|---|---|---|
| Q1 | AE 替你省掉了多少本地标签？ | 零标签的 AE 与"老办法：S2 统计特征 + k 个本地随机标签"正面比较。S2 要到 k = L_saved 才追上 AE |
| Q2 | 用上 AE 后，还要不要采标签？什么时候必须采？ | AE 加 k 个标签的增益（剂量曲线），以及它与零标签迁移质量 M 的关系。M 用前 50 个本地标签就能估计 |
| Q3 | 已有一次集中调查时，新标签怎么采？ | 情景 B：在全国分散采（SRS）、在原调查区扩采（EXT）、按 Betti 分配（BA），以及集中标签与分散标签的交换率 |

**确认性假设**（检验细节见第 7 节）
- **H1（Q1）**：在确认性目标域中，零标签 AE 胜过"S2 + 200 个本地随机标签"的域，占比超过一半。
- **H2（Q2）**：用上 AE 后，200 个本地标签带来的增益，随零标签迁移质量 M 上升而下降。
- **H3**：只有 H1 成立后才检验，逐任务族（LCZ、LUCAS）检验 H1。

**术语**

| 术语 | 含义 |
|---|---|
| 任务族 | LCZ（城市形态，17 类）、LUCAS（土地覆盖，7 类）。作物为锚点任务，不进入确认性检验 |
| 目标域、源池 | 被预测的城市或国家；其余域的已标注样本 |
| Z0、RT_k、RT全 | 只用源池；源池加目标域 k 个随机标签；源池加全部候选标签 |
| Δ_V(A → B) | 模型 B 相对模型 A 的稳健版"同 OA 下的 BA"差（第 6 节） |
| e(k) | Δ_V(S2 的 RT_k → AE 的 Z0)：零标签 AE 相对 S2 + k 个标签的优势；e(0) 即零标签时 AE 相对 S2 |
| L_saved | AE 省掉的标签数：e(k) 首次降到 0 时的 k |
| g(k) | Δ_V(AE 的 Z0 → AE 的 RT_k)：用上 AE 后 k 个本地标签的增益 |
| M | 零标签迁移质量：AE 的 Z0 在前 50 个本地候选样本上的总体精度（%） |
| S0、S1、k1 | 情景 B 的已有调查（100 个集中标签）、新增标签、新增数（100、300） |

## 4. 划分与抽样（与试点相同，种子前缀为 nc_main_v1）

**测试与候选**
- 网格与缓冲：
  - LCZ：2 km 网格，原点 0；缓冲 500 m。
  - LUCAS：EPSG:3035 中的 10 km 网格，原点平移 5 km；缓冲 1 km。
- 坐标先四舍五入到 1 m。
- 测试网格：网格按 (x 编号, y 编号) 数值升序排列，`rng.choice` 抽 round(0.3 × 网格数) 个；种子 `nc_main_v1_split_{域}`。
- 候选：不在测试网格内，且到最近测试样本的距离 ≥ 缓冲。

**情景 A 的抽样顺序**
- 候选按编号排序后 `rng.permutation`，种子 `nc_main_v1_srs_{域}_r{r}`，r = 0、1、2。
- 剔除缺失后保持相对次序；RT_k 取前 k 个。

**情景 B 的调查格与调查区**
- 调查格：
  - LCZ 为 2 km 格（与测试网格相同）；
  - LUCAS 为 EPSG:3035 中的 40 km 格，原点平移 5 km。LUCAS 点位稀疏，10 km 格只有几个点，放不下"每格 10 个"的集中调查。
- 合格调查格：含 ≥ 10 个候选的格。
- 调查区：对合格调查格的候选质心做 KMeans（8 个区，n_init = 10，random_state = 0），格按 (x 编号, y 编号) 升序输入；其余格按最近质心归区。

**S0（已有调查，100 个）**：规则同 RSE。
1. 按各区候选数 PPS 抽 2 个区（Efraimidis–Spirakis）；所选区内合格格不足 30 个时，按同一顺序追加区。
2. 在所选区的合格格中，按候选数 PPS 抽 10 个格。
3. 每格简单随机抽 10 个。

种子为 `nc_main_v1_S0_{域}_r{r}`，r 与情景 A 的抽样号一一对应。

**S1（新增，k1 ∈ {100, 300}，k1 = 100 是 k1 = 300 的前缀）**

| 策略 | 做法 |
|---|---|
| SRS | 按情景 A 的同一顺序 π_r 取前 k1 个，跳过 S0 |
| EXT | 只在 S0 所在区内按 π_r 取前 k1 个。区内候选不足时，按 S0 的区顺序追加区（新增规则；RSE 中未发生） |
| BA | Betti 分配，与 RSE 相同：8 个区，γ_g 为区的候选占比，n⁰_g 为 S0 在该区的个数；每步把名额给边际增益 γ_g[(n⁰_g + n_g + 1)^(−½) − (n⁰_g + n_g + 2)^(−½)] 最大、且未满容量的区；区内按 π_r 取 |

**种子整数**：md5(utf-8) mod 2^31。

## 6. 度量

**τ 族与 BA**（与 RSE 相同）
- ℓ = log P − τ·log π̂，τ = −2…2，步长 0.05；π̂ 为测试集平均预测概率，不用标签。
- BA = 各域 BA 类别召回率的平均。

**主指标 Δ_V(A → B)**（稳健版同 OA 下的 BA）
- BA⁺_X(o)：模型 X 的 τ 路径上，OA ≥ o 的所有点中的最高 BA。路径点包括相邻 τ 之间线性插值得到的点。
- 窗口锚点 m = min(OA_A(τ=0), OA_B(τ=0))，网格 o = m − 4.0, …, m，共 41 点。
- Δ_V = 网格上 BA⁺_B(o) − BA⁺_A(o) 的平均。没有缺失。
- 与 RSE 原指标的差别：原指标只取 OA 恰好等于 o 的点，B 整体向右上移时只读到 B 被支配的尾部。作物 9 国上两者的国家值相差 ≤ 0.10 pp。

**次指标 Δ_D(A → B)**（等增益方向距离，方向 (1, 1)）
- 对点 a，d_X(a) = max_{p ∈ X 的路径} min(p_OA − a_OA, p_BA − a_BA)。每段路径在两端点及两分量相等处求值。
- W_X = {(o, BA⁺_X(o)) : o = OA_X(0) − 4.0 … OA_X(0)}。
- Δ_D = ½[mean_{a∈W_A}(d_B(a) − d_A(a)) + mean_{a∈W_B}(d_B(a) − d_A(a))]。
- 单位：OA 与 BA 可同时提高的百分点。

**域级量**（每个量先在每次抽样内算，再对 3 次抽样取平均）
- e(k) = Δ_V(S2 的 RT_k → AE 的 Z0)，k = 0 时为 Δ_V(S2 的 Z0 → AE 的 Z0)；d = e(200)。
- g(k) = Δ_V(AE 的 Z0 → AE 的 RT_k)；g(全) 对应 RT全。
- 参照：S2 的剂量 h(k) = Δ_V(S2 的 Z0 → S2 的 RT_k)。
- TESSERA：d_T = Δ_V(S2 的 RT200 → TESSERA 的 Z0)。
- M：AE 的 Z0 在 τ = 0 时，对 r = 0 抽样顺序前 50 个候选样本（剔除缺失后）的总体精度。这正是实践者花 50 个标签就能得到的迁移质量估计。另报测试集上的值作对照。

**AE 省掉的标签数 L_saved**（每个域）
- 在 {0, 50, …, 最大 k} 上，对 e(k) 做单调不增的等权保序回归（PAV）。
- 取首次 ≤ 0 的 k，线性插值。e(0) ≤ 0 时记 0；e(最大 k) > 0 时在最大 k 处右截尾。
- 按任务族用 Kaplan–Meier 估计 S(k)，即 AE 省掉 ≥ k 个标签的域所占比例，并报中位 L_saved。

**情景 B 的量**（AE，LightGBM，Δ_V；配对在同一抽样内）
- B1 补在哪里：Δ_V(EXT k1 → SRS k1)、Δ_V(SRS k1 → BA k1)，k1 = 100、300。
- B2 已有调查的价值：Δ_V(Z0 → S0)；补采增益 Δ_V(S0 → S0 + S1)，与情景 A 的 Δ_V(RT100 → RT(100 + k1)) 并列。
- X1 同标签总数比较：
  - S0 对 RT100；
  - S0 + {SRS, EXT, BA}100 对 RT200；
  - S0 + {SRS, EXT, BA}300 对 RT400。
- X3 交换率与成本：
  - 随机样本曲线：族内平均 g(k)，k = 0、50、100、200、400，PAV 单调化后线性插值。
  - 各配置 Δ_V(Z0 → 配置) 的族内平均，换算为等价随机标签数 k_eq；交换率 = k_eq ÷ 标签总数。
  - 集中样本的价值按 S0 与 S0 + EXT 两档换算。
  - 成本表：c ∈ {1, 2, 3}，预算 K ∈ {100, 200, 400}，规则同 RSE rev1 第 7 条。
  - 族内域级 bootstrap 2,000 次，报 90% 区间。

**单元测试（冻结代码前必须通过）**
1. 作物 9 国的 Δ_V 与 RSE 登记值之差 ≤ 0.10 pp。
2. Δ(A, B) = −Δ(B, A)，误差 ≤ 1e-12。
3. 模型与自身重排副本比较，结果为 0。
4. 合成前沿平移 (0, +δ) 时 Δ_V = δ。
5. 合成前沿平移 (+h, 0)、(+t, +t) 时 Δ_V ≥ 0 且 Δ_D > 0。
6. 情景 B 的选样在作物数据上逐位复现 RSE 的 `selection/` 文件。

## 7. 假设检验与判定（写死）

**确认性分析集**：LCZ 与 LUCAS 的全部情景 A 合格目标域；主学习器 LightGBM；主指标 Δ_V。

| 编号 | 假设 | 检验 |
|---|---|---|
| H1 | P(d > 0) > 1/2，d = e(200) | 两族合并，精确二项单侧检验 |
| H2 | β < 0，模型 g_i(200) = α + γ·[族 = LUCAS] + β·M_i + ε | OLS，HC3 稳健标准误，单侧 t |
| H3_LCZ、H3_LUCAS | 各族 P(d > 0) > 1/2 | H1 被拒绝后才检验；各族精确二项单侧，两者之间用 Holm |

- H1 与 H2 之间用 Holm，族错误率 α = 0.025（单侧）。
- H3 在 H1 成立后，以 α = 0.025 做 Holm。

**主张措辞规则**（只依赖上述结果）
- **"多数地区 AE 省掉 200 个以上标签"**：H1 被拒绝，且 Δ_D 版本 d > 0 的占比（点估计）> 1/2 时才写；否则写"依赖度量"，两者都报告。
- **逐族主张**：只对 H3 被拒绝的族写。
- **预算规则**：只有 H2 被拒绝时才写。M₁ 为拟合的 g(200) 降到 1 pp 时的 M，附 bootstrap 95% 区间。措辞为："先用 50 个本地标签测零标签迁移精度。高于 M₁ 时，再采 200 个标签预期提升不足 1 pp；低于 M₁ 时，应采标签。"
- **"卫星嵌入"措辞**：TESSERA 可用的域上，d_T > 0 的占比的 95% Clopper–Pearson 下界 > 0.5 时，标题与摘要写"satellite embeddings"；否则写"AlphaEarth embeddings"，TESSERA 结果原样报告。
- **"不依赖学习器"措辞**：逻辑回归与随机森林各自 d > 0 的占比（点估计）都 > 1/2，且 g(200) 与 M 的相关同为负时才写。
- **情景 B 的读法**（与 RSE 相同）
  - B1：95% CI ⊂ (−1, +1) 时写"补采位置的影响小于 1 pp"；CI 不含 0 时写方向与大小；其余写"未能区分"。
  - X3：集中与随机两条曲线之差的 90% 区间覆盖 0 时，不报交换率点估计。

**只报估计值（不检验）**
- d 的均值、中位数与区间；
- e(k)、g(k)、h(k) 的剂量曲线，L_saved 的 Kaplan–Meier 曲线；
- 用尽全部候选时能否追上（逐域）；
- τ = 0 的 OA、BA 读数；
- 情景 B 的全部量；
- 作物锚点与跨年新目标。

**缺失与失败**：Δ_V 没有缺失。拟合失败的域在修复后重跑；仍失败的剔除并报告。
