# NC 主实验：实现约定（方案 NC_PLAN_v6 未写明的边界情形）

2026-10-06 写定，早于任何正式拟合。两份独立实现（`nc_main_analyze.py`、`nc_main_indep.py`）都按下列约定执行，并已在合成冒烟数据上逐值核对一致。这些约定只处理方案未写明的边界情形，不改动方案中的任何定义或判定规则。

1. **失败剔除的范围**：任一学习器的任一拟合重试后仍失败，整个域退出全部分析，包括 LightGBM 的确认性分析，并在报告中列出。
2. **d 恰为 0**：计为非正，不改变 n。
3. **bootstrap 中设计矩阵秩不足**：这类重抽样中 β 不可估计，与 β̂_b ≥ 0 的重抽样一样不计入。
   - q 只报 β̂_b ≥ 0 所占比例，分母为 2,000。
   - 是否写"无界"，按两类合计所占比例 > 2.5% 判定。
   - 正式数据中秩不足的情况不会出现。
4. **分位数**：用冻结的 `analyze_confirm.q_interval(level=0.95)`，即逆经验分布、不插值，先 round 到 6 位再取整。独立实现用整数运算，结果相同。
5. **作物 L_saved**：先把 e(k) 按两半平均到国家，再做保序回归与插值。
6. **右删失**：L_saved 记为"> k_max"，k_max 因域而异，为 400、800 或 1,600。
   - 主实现在 CSV 中写 L_saved = k_max 且 censored = True；独立实现写 NaN 且 censored = True。
   - "L_saved > k"的比例按 ê(k) > 0 计算，删失域计入。
7. **BA 类别**：按方案在剔除缺失之前确定。已核对正式数据：剔除缺失后，47 个域中所有 BA 类别在测试集中仍有 ≥ 10 个样本。剔除影响 capetown、lisbon、newyork 三个城市，测试集分别减少 14、10、12 个样本。
8. **附录学习器的 d、g(200)**：在同一学习器内配对，即该学习器的 S2 RT200 对其 AE Z0。"d > 0 的比例"取 47 个域合并后的比例。
9. **作物 M 的并列**：RSE 的 `P_pool` 以 float16 存储，argmax 的并列按首个类别处理（np.argmax）。
10. **M₁ 的计算与报告**：只要点估计 β̂ < 0 就计算 M₁ 与 bootstrap，但只在 H2 被拒绝时写入主张与主图 2。
