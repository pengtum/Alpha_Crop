## 0. 目的、问题与术语

**要回答的问题**：模型迁移到一个没有本地标签的新地区后，换用卫星嵌入，值多少个本地随机标签？这个"汇率"在什么情况下成立，在什么情况下失效？

**为什么这样问**：数据稀缺地区的机构需要在两件事之间分配预算：采集本地标签，或者换用更好的表征。已有工作只报告"标签比例–精度"曲线，或在同一地区内比较嵌入，没有在地理迁移之后、以本地标签为货币测量表征的价值，也没有给出何时该换表征、何时该采标签的规则。

**试点的启示**（描述性）
- 多数目标域中，AE 胜过 200 个本地标签。
- 零标签迁移崩溃的域是例外：几十到几百个标签就胜过 AE。这类域包括 Melbourne，以及作物中的 RO、PT。
- 因此本方案同时检验两件事：
  - "多数地区嵌入更值"；
  - "优势随零标签迁移质量变化"。

**确认性假设**（第 7 节给出检验细节）
- **H1**：在确认性目标域中，AE 相对 S2 的增益超过 200 个本地随机标签增益的域，占比超过一半。
- **H2**：这一优势随零标签迁移质量 M 上升而增大。M 用一个实际可得的量：前 50 个本地标签上零标签模型的精度。
- **H3**：只有 H1 成立后才检验，逐任务族（LCZ、LUCAS）检验 H1。

**术语**

| 术语 | 含义 |
|---|---|
| 任务族 | LCZ（城市形态，17 类）、LUCAS（土地覆盖，7 类）；作物为锚点任务，不进入确认性检验 |
| 目标域 | 被预测的城市（LCZ）或国家（LUCAS） |
| 源池 | 其余域的已标注样本 |
| Z0 | 只用源池训练，目标域零标签 |
| RT_k | 源池加目标域 k 个随机样本的标签 |
| RT全 | 源池加目标域全部候选样本的标签 |
| Δ_V | 稳健版"同 OA 下的 BA"（主指标，第 6 节） |
| Δ_D | 等增益方向距离（次指标，第 6 节） |
| Δ_R | 零标签时 AE 相对 S2 的增益 |
| Δ_L(k) | k 个本地标签带来的增益 |
| d | Δ_R − Δ_L(200)，每个目标域一个值 |
| M | 零标签迁移质量：前 50 个本地标签上 Z0 的总体精度 |
| L_AE | 标签当量：本域标签增益曲线首次达到 Δ_R 时的 k |

## 4. 目标域内的划分（与试点相同，种子前缀换为 nc_main_v1）

- **网格与缓冲**
  - LCZ：2 km 网格，原点 0；缓冲 500 m。
  - LUCAS：EPSG:3035 中 10 km 网格，原点平移 5 km；缓冲 1 km。
- **坐标**：先四舍五入到 1 m。
- **测试网格**：网格按 (x 编号, y 编号) 数值升序排列，`rng.choice` 抽取 round(0.3 × 网格数) 个。种子为 `nc_main_v1_split_{域}`。
- **候选集**：不在测试网格内，且到最近测试样本的距离 ≥ 缓冲距离。
- **抽样顺序**：候选集按编号排序后 `rng.permutation`，种子为 `nc_main_v1_srs_{域}_r{r}`，r = 0、1、2。剔除缺失样本后保持相对次序。
- **种子整数**：md5(utf-8) mod 2^31，与 RSE 相同。

## 5. 臂、学习器与训练

| 臂 | 训练集 | 学习器 |
|---|---|---|
| Z0 | 源池 | LightGBM、逻辑回归、随机森林 |
| RT_k | 源池 + 抽样顺序前 k 个；k ∈ {50, 100, 200, 400, 800, 1,600}，只取 k ≤ 候选数 | LightGBM：全部 k；逻辑回归、随机森林：只有 k = 200 |
| RT全 | 源池 + 全部候选 | LightGBM |

- **抽样次数**：RT_k 每个 k 做 3 次抽样；小预算是大预算的子集。
- **特征**：AE、S2，以及有覆盖时的 TESSERA，各自独立训练。
- **权重**：类别权重 = 源池类别频率的倒数（RSE 的 `class_weights_from`）。源样本权重为类别权重，目标样本为 50 × 类别权重。
- **LightGBM**：参数与 RSE、试点相同，num_class 为 17 或 7，种子 `nc_main_v1_fit_{域}_{特征}_{臂}_r{r}`。
- **逻辑回归**
  - 缺失值用训练集中位数填补；在训练集上标准化。
  - 模型：L2、C = 1、lbfgs、max_iter = 1,000，多项式。
  - 超参数事先固定，不在任何数据上调参。
- **随机森林**：500 棵树，max_features = sqrt，min_samples_leaf = 1；缺失值用训练集中位数填补；参数与 RSE 相同。
- **线程**：数固定为 2。记录各库版本。
- **规模**：每个目标域约 70–90 次拟合，共约 5,000 次。在本机 2 线程下约 60–90 小时，可分批断点续跑。

## 6. 度量

**τ 族与 BA**（与 RSE 相同）
- ℓ = log P − τ·log π̂，τ = −2…2，步长 0.05；π̂ 为测试集平均预测概率，不用标签。
- BA 为各域 BA 类别召回率的平均。

**主指标 Δ_V（稳健版同 OA 下的 BA）**：比较模型 A（参照）与 B。
- 对每个模型 X，BA⁺_X(o) = 其 τ 路径上（含相邻 τ 之间的线性插值点）OA ≥ o 的所有点中的最高 BA。
- 窗口锚点 m = min(OA_A(τ=0), OA_B(τ=0))，网格 o = m − 4.0, m − 3.9, …, m，共 41 点。
- Δ_V = 网格上 BA⁺_B(o) − BA⁺_A(o) 的平均。两个模型总能到达窗口，所以没有缺失。
- 与 RSE 原指标的区别：
  - 原指标只取 OA 恰好等于 o 的点。当 B 整体向右上移时，原指标只能读到 B 被支配的尾部点。
  - 在作物 9 国上，两者的国家值相差 ≤ 0.10 pp。

**次指标 Δ_D（等增益方向距离，方向 (1, 1)）**
- 对点 a，d_X(a) = max_p∈X 路径 min(p_OA − a_OA, p_BA − a_BA)。每段 τ 路径在两端点及两分量相等处求值。
- W_X = {(o, BA⁺_X(o)) : o = OA_X(0) − 4.0 … OA_X(0)}。
- Δ_D = ½[mean_{a∈W_A}(d_B(a) − d_A(a)) + mean_{a∈W_B}(d_B(a) − d_A(a))]。
- 单位：OA 与 BA 可同时提高的百分点。

**域级量**
- Δ_R = Δ_V(S2 的 Z0 → AE 的 Z0)。
- Δ_L(k) = AE、S2 两种特征下 Δ_V(Z0 → RT_k) 的平均，每种特征先对 3 次抽样取平均。
- d = Δ_R − Δ_L(200)。
- Δ_D 版本同样计算。
- TESSERA：d_T = Δ_V(S2 的 Z0 → TESSERA 的 Z0) − Δ_L(200)，其中 Δ_L(200) 与上式相同。

**调节变量 M**
- 定义：AE 与 S2 两个 Z0 模型在 τ = 0 时、对第 r = 0 次抽样前 50 个候选样本的总体精度的平均（百分数）。
- 这 50 个样本正是 RT50 所用的标签，代表实践者花 50 个标签就能得到的迁移质量估计。
- 测试集上的 Z0 OA 作为对照另报。

**标签当量 L_AE**（每个域）
- 在该域的 {0, 50, …, 最大 k} 上，对 Δ_L(k) 做等权保序回归（PAV），取首次达到 Δ_R 的最小 k，线性插值（RSE 的 `k_eq`）。
- Δ_R 超过最大 k 处的值时，按右截尾处理。
- 按任务族用 Kaplan–Meier 估计 S(k)，即 AE 抵得过 k 个标签的域所占比例，并报告中位 L_AE。

**交叉点 M\***：H2 回归中拟合 d = 0 处的 M，用域级 bootstrap（2,000 次，按族分层）给出 95% 区间。

**单元测试（冻结代码前必须通过）**
1. 作物 9 国的 Δ_V 与 RSE 登记值之差 ≤ 0.10 pp。
2. Δ(A, B) = −Δ(B, A)，误差 ≤ 1e-12。
3. 模型与自身重排副本比较，结果为 0。
4. 合成前沿平移 (0, +δ) 时，Δ_V = δ。
5. 平移 (+h, 0)、(+t, +t) 时，Δ_V ≥ 0 且 Δ_D > 0。

## 7. 假设检验与判定（写死）

**确认性分析集**：LCZ 与 LUCAS 的全部合格目标域，主学习器 LightGBM，主指标 Δ_V。

| 编号 | 假设 | 检验 |
|---|---|---|
| H1 | P(d > 0) > 1/2 | 两族合并，精确二项单侧检验 |
| H2 | β > 0：d_i = α + γ·[族 = LUCAS] + β·M_i + ε | OLS，HC3 稳健标准误，单侧 t |
| H3_LCZ、H3_LUCAS | 各族 P(d > 0) > 1/2 | H1 被拒绝后才检验；各族精确二项单侧，两者之间 Holm |

**错误率控制**
- H1 与 H2 用 Holm 控制族错误率：α = 0.025，单侧。
- H3 在 H1 成立后，同样以 α = 0.025 做 Holm。

**主张措辞规则**（只依赖上述结果）
- **"多数地区嵌入更值"**：H1 被拒绝，并且 Δ_D 版本 d > 0 的占比（点估计）> 1/2，正文才写。否则写"依赖度量"，两者都报告。
- **逐族主张**：只对 H3 被拒绝的族写。
- **预算规则**：只有 H2 被拒绝才写"迁移质量 M 高于 M\* 时，先换表征；低于时，先采标签"，并附 M\* 及其区间。
- **"卫星嵌入"措辞**：在 TESSERA 可用的域上，d_T > 0 的占比的 95% Clopper–Pearson 下界 > 0.5 时，标题和摘要写"satellite embeddings"；否则写"AlphaEarth embeddings"，TESSERA 结果原样报告。
- **"不依赖学习器"措辞**：逻辑回归与随机森林各自 d > 0 的占比（点估计）都 > 1/2 时才写。

**只报估计值**（不检验）
- d 的均值、中位数与 95% 区间；
- 各 k 的 Δ_L 剂量曲线，以及 L_AE 的 Kaplan–Meier 曲线与中位数；
- 用尽全部候选时能否追上 AE（逐域）；
- 交互 I(k)；
- τ = 0 的 OA、BA 读数；
- 作物锚点与跨年新目标的结果。

**缺失与失败**：Δ_V 没有缺失。拟合失败的域在修复后重跑；仍失败的，剔除并报告。

## 9. 样本量与功效（依据：17 个已有域按 Δ_V 的描述性重算）

**已有域的情况**
- d > 0 的占比为 0.71（12/17），d 的中位数为 +4.4，均值为 +1.1。
- 均值被 RO、PT、Melbourne 等崩溃域拉低。
- d 与测试集 Z0 OA 的 Spearman 相关为 0.64。

**预计确认性域数**：约 59（LCZ 39、LUCAS 20）。

**H1**
- 若真实占比为 0.71：在 α = 0.0125（Holm 第一步）下功效 0.82，在 α = 0.025 下为 0.88。
- 若真实占比为 0.65：功效分别为 0.49 和 0.60。

**均值 t 检验**：同样条件下功效只有约 0.13，所以不用作 H1。

**H2**：按已有域的关系重抽样模拟，功效接近 1。

**H3**：LCZ（39 城）功效约 0.65，LUCAS（20 国）约 0.26–0.44。逐族主张未达显著时，只报告估计值。
