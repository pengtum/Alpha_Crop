设计：11 个目标国×2 个冻结空间半区。每个目标国分别使用其他10国之一的5,000条外国标签；直接取原冻结50,000外国池中对应源国的5,000条，继承跨境1公里缓冲。另为每个单元建立等样本量多源对照 MULTI5K：原10个源国各固定随机抽500条，共5,000。源池固定，不以性能选源。旧MULTI50K只作为不同总样本量的背景参照，不能单独用于解释来源多样性。

两个特征 AE/S2；两者使用相同训练下标。LightGBM 300轮、固定参数、每进程2线程；拟合随机种子复用原单元/抽样种子。目标标签类内权重50倍、类别权重来自各自外国池；外国池未出现的类别权重为1，明确报告这种情况。外国池总量均为5,000，因而单源和MULTI5K目标权重可比；不得将与50,000池的差异全部归因于多样性。

场景A：Z0，随机50/100/200/400标签，各3次嵌套抽样。场景B：已有100标签S0，及新增100/300标签的EXT/SRS/BA策略，各3次。全部复用冻结目标候选池与selection清单，保留原始样本。目标单独模型TGT不重训，引用原只读概率。RF 500棵，Z0和RT200×3次，作为学习器敏感性检验。对于训练中未出现的类别，预测概率显式置零并重新归一化，避免多分类固定10输出产生数值伪概率；新增目标标签可解锁新类别。

数量：242个源配置×单元（220单源，22个MULTI5K）。每配置LightGBM 68次，不含复用TGT；RF 8次。合计16,456个LightGBM及1,936个RF，共18,392次新拟合。核心场景A为6,292次，场景B为10,164次，RF为1,936次。先实际计时小样例，再自动按核心→场景B→RF→分析顺序运行，可断点续跑。

输出只到独立results/single_source_20261009；保存P_test float32、训练/选择/代码哈希、计时和失败记录。不保存P_pool：本扩展的冻结选样不依赖新模型，OA–BA分析只需P_test。磁盘余量低于4GB即停止并保留进度。

评估：测试标签只用于评分，不用于选样或调参。复用81个tau及原OA–BA包络函数，目标big类别固定>=30；相同OA可达率<50%的比较明确缺失，不外推。先计算全部目标类别的BA和OA，再单列仅源池已覆盖类别的诊断指标，以及未覆盖类别比例、补采后新增类别数。预测为缺失类的限制为监督闭集设置，不等同于对foundation model本身的零样本能力评判。
