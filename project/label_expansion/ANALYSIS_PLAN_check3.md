# 检验 3 预注册方案：把跨境损失拆成"类别比例"与"特征分布"两部分

写于 2026-09-24，在运行任何检验 3 的模型之前。

## 问题

目标国 T 本国训练的模型精度高于用其他 10 国训练的留一国（LOCO）模型，这个差就是跨境损失。损失中有多少来自类别比例不同（先验偏移，p(y) 变化，以及类别集合不同），有多少来自同一作物在两国的特征分布不同（条件偏移，p(x|y) 变化）？AE 和 S2 在这两部分上是否不同？

## 设计（`check3_decomposition.py`）

**国家与特征**：11 国轮流作为目标国 T，分类特征为 AE 和 S2，只用 AE∩S2 共有的地块（dataset_v2）。

**目标国划分**：去掉质心和面积完全相同的重复地块后，按 70/30 随机划分为 pool 与 test（random_state=42）。所有模型都在同一个 test 上评估。

**三个模型**（LightGBM：500 棵树，早停 50 轮，其余参数同 common.LGBM_PARAMS，seed 0）：

1. **LOCO**：外国池为其余 10 国各随机 10,000 个地块（不足则全取），训练时用类别平衡权重，早停验证集取外国池的 10%（分层）。
2. **WITHIN**：用 T 的 pool 训练（其中 10% 作早停验证），类别平衡权重。这是本国上限。
3. **LOCO-PM**（prior-matched）：外国池不做类别平衡，而是用重要性权重 π_T(y)/π_F(y)，把训练先验改成 T 的真实先验。它是"在训练时校正先验"的对照。

每个模型保存它在 T 的 pool 和 test 上的预测概率，后面的修正全部在这些概率上事后进行。

**事后修正**（作用于 LOCO 的概率 p(y|x)，训练先验 π_train 按类别平衡权重视为均匀分布）：

| 代号 | 修正方式 | 所需信息 |
|---|---|---|
| L0 | 不修正 | — |
| LS | 只允许 T 中存在的类：其余类概率置零后重新归一化 | 目标国种哪些作物（类别集合） |
| PO | q(y\|x) ∝ p(y\|x)·π_T(y)，π_T 取 T 的 pool 中的真实比例 | 目标国类别比例（相当于官方农业统计） |
| PEM | 按 Saerens et al. (2002) 的 EM，在 T 的 pool 上无标签估计 π̂_T（最多 200 次迭代，容差 1e-6），再按 PO 的方式修正 | 无 |
| PK50、PK200 | 从 T 的 pool 随机取 k 个标签估计 π̂_T（Laplace 平滑 +1），再按 PO 的方式修正；3 个种子 | k 个目标国标签 |

**WITHIN 的对应版本**：WITHIN 不修正，记为 W0；WITHIN 按 T 的真实比例修正，记为 WPO。

## 指标

- OA（总体精度）；
- ba_ge30（在 test 中地块数 ≥30 的类别上计算的平衡精度，是项目主指标）；
- macro-F1；
- 另报全类平衡精度 ba。

## 分解定义（按指标分别定义，因为每个指标下"最优决策"不同）

**OA**（最优决策需要使用真实先验）：
- 总损失 = OA(WPO) − OA(L0)
- 先验部分 = OA(PO) − OA(L0)
- 条件部分 = OA(WPO) − OA(PO)

**ba_ge30**（类别平衡的决策已接近最优，所以先验修正预期无益甚至有害）：
- 总损失 = ba(W0) − ba(L0)
- 类别集合部分 = ba(LS) − ba(L0)
- 条件部分 = ba(W0) − ba(LS)
- 另外报告 ba(PO) − ba(L0)，用来检验"先验修正会降低平衡精度"的预期。

**比例**：各部分占总损失的比例。先在每个 (T, 特征) 上计算，再在 11 个目标国上取中位数，并报告按目标国重抽的 bootstrap 95% CI。

## 主要问题与判定

1. **OA 下先验部分占总损失的比例**：报告中位数与 CI。若中位数 ≥ 30%，判为"类别比例是 OA 跨境损失的主要来源之一"。
2. **ba_ge30 下**：类别集合部分与条件部分各占多少。预期条件部分占主导（≥ 70%）；ba(PO) − ba(L0) ≤ 0。
3. **无标签与少标签的先验估计能恢复多少先验部分**：OA 下计算 (PEM − L0)/(PO − L0)，以及 PK50、PK200 的同一比例。
4. **AE 与 S2 的损失构成是否不同**：在 11 个目标国上配对比较先验部分比例与条件部分（Wilcoxon 检验）。按项目惯例，平均差 ≥ 1 pp 且 p < 0.05 才判为有差异。
5. **先验部分与类别构成距离的关系**：计算先验部分（pp）与 class_js（T 与外国池类别分布的 JS 距离）的 Spearman 相关，作为描述性结果。

## 敏感性分析

- LOCO-PM 与 PO 的一致性：训练时校正与事后校正是否给出相近的 OA。
- 去掉 RO：RO 只有 3 类，而且标签体系不同。
- 去掉 LV：LV 的 S2 缺马铃薯和草莓。

## 已知局限

- 单一种子，外国池为每国 10k 的子样本。
- LightGBM 的概率校准会影响 PO 和 PEM 的效果，这里不做额外的概率校准。
- π_T 取自 pool 的真实比例，是"官方统计完全准确"的理想情况。
- 条件部分中混有标签语义不一致的影响，例如 RO 的 other_crops 含义与其他国家不同，这一部分无法与真正的特征分布差异分开。
