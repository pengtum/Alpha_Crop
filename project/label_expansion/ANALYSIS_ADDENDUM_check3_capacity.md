# 检验 3 事后补充：训练容量一致性检验（不属于预注册分析）

写于 2026-09-24。主分解的结果已经看过，本检验由独立复核的发现引出，**不属于预注册分析**，结论需标注为事后稳健性检验。

## 起因

复核发现，主链中各模型的早停轮数差别很大：
- 类别平衡权重的模型（L0、CMB、W0）在类别平衡的验证集上早停，中位数约 30–48 轮；
- 自然先验的模型（CMN、W-nat）约 85 轮。

在同一外国池上，把 LOCO 改为固定 300 棵树，6 个国家的 L0 平均 OA 为：AE 从 56.5 升到 61.6，S2 从 53.1 升到 61.4。先验修正后的 OA 几乎不变，所以 PO − L0 缩小约 40%。

这说明"类别构成部分"（PM − L0）可能被 L0 的训练不足放大了。

## 设计（`check3_capacity.py`）

对 11 国 × {ae, s2}，重训主链的 6 个模型：L0、PM、CMN、W-nat、CMB、W0。

- 训练集与主分析完全相同：f_tr、cm_tr、p_tr 按原脚本的随机数顺序重放。
- 唯一的改动是训练方式：一律固定 300 棵树、不早停。
- 其余参数与权重都不变。

## 报告方式

- 两种设置（早停 / 固定 300 棵）的分解并列报告：各部分的 pp 与合并比例。
- 若固定容量下 OA 的类别构成合并比例 < 30%，把主要问题 1 的结论降级为"依赖训练设置"。若仍 ≥ 30%，说明结论方向稳健，但报告中以两者的区间作为效应大小。
- 同时报告 PK50 相对 PO 的恢复率在两种设置下的数值。
