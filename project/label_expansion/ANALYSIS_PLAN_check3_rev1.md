# 检验 3 方案修订 v1（在看结果之前）

写于 2026-09-24。原方案 `ANALYSIS_PLAN_check3.md`（sha256 前 16 位 08b3d2710f0aefa7）保持冻结。本修订与原方案冲突时，以本修订为准。

## 披露

- **已看过的数字**：一次 RO 冒烟测试的输出（20 棵树，外国池每国 800 个）。LOCO 的 test OA 为 0.21，WITHIN 为 0.72，LOCO-PM 为 0.63。除此之外，我没有看过检验 3 的任何真实结果：check3.log 只统计过行数和报错信息，没有打开 results/check3/ 下的概率文件。两位审查 agent 也没有接触任何结果。
- **训练中断与续跑**：训练在第 7 个目标国 PT 处中断。原因是 PT 的候选池中草莓只有 1 个地块，strat_split 报错。修改 strat_split（把仅含 1 个样本的"稀有层"并入最大类的层）后，从 PT 续跑。该修改只影响 PT 的内部训练/早停划分；AT–LV 的输出不变。
- **随机种子**：LightGBM 实际使用 random_state=42（common.LGBM_PARAMS），不是原方案写的 seed 0。

## 为什么修订

独立方法论审查用合成实验指出原方案的定义有三个问题：

1. **事后先验修正依赖概率校准，且分解有顺序依赖。** 交互项可能大于总损失；"先修先验"和"先修条件"两条路径给出的先验比例甚至符号相反。
2. **"WITHIN 加事后先验修正"不是有效的 OA 上界。** 类别平衡训练得到的概率偏平，乘以 π_T 后过度偏向多数类。
3. **WITHIN 与 LOCO 的训练量、各类样本数不匹配**（相差 1.5–3.4 倍，少数类相差几十倍）。这会被错算为"条件部分"。另外，8/11 个目标国含全部 10 类，这些国家的 ba"条件部分 ≥70%"按定义必然成立。

## 主分解：训练时链式替换（不依赖概率校准，每一步只改变一个因素）

新训练的模型（`check3_supp.py`），对 11 个目标国 T × {ae, s2} 各训练一次：

| 代号 | 训练数据 | 权重 |
|---|---|---|
| W-nat | T 的 p_tr | 不加权（自然先验） |
| CMB | 外国地块，按 T 的 p_tr 各类计数抽样 | 类别平衡 |
| CMN | 同 CMB 的样本 | 不加权（即 T 的自然先验） |
| L-cal | 重跑 LOCO（deterministic），并保存外国校准集的预测 | 类别平衡 |
| W0-sp、Wnat-sp | 空间分块划分下 T 的 pool | 类别平衡 / 不加权 |

**CMB/CMN 的抽样**：先从 f_tr 中各类无放回抽取，不足时从未进入外国池的其他外国地块补足；再不足就全部取用，并记录补足比例与短缺量。早停集从 f_va 按 T 的 p_va 计数同样抽取。

**OA 的链**：L0 → PM → CMN → W-nat
- 类别构成部分 = PM − L0：训练先验改为 π_T，同时去掉 T 中不存在的类。
- 样本量部分 = CMN − PM：训练数据量与各类计数改为与 T 一致。
- 残差（域）部分 = W-nat − CMN：只剩"数据来自哪个国家"这一个差别。
- 总损失 = W-nat − L0。

**ba_ge30 的链**：L0 → LS → CMB → W0
- 类别集合部分 = LS − L0，只在 LT、LV、RO 上不为 0。
- 样本量部分 = CMB − LS。
- 残差（域）部分 = W0 − CMB。
- 总损失 = W0 − L0。

**说明**：
- "残差部分"混有条件偏移、标签语义差异、类内细类构成差异和空间自相关，报告时统称"域残差"。在 AE 与 S2 的对比中，标签相关的混杂大体一阶抵消。
- 所有指标都在同一个 T 的 test 上计算。W0、W-nat 在 pool 上的预测属于样本内预测，一律不使用。

## 汇总与判定

- **汇总方式**：
  - 各部分报告 pp，按国家报告，并在 11 国间取均值与中位数；
  - 合并比例 = Σ部分 / Σ总损失，CI 用按目标国重抽的 cluster bootstrap（5,000 次）；
  - 另报"留一国"范围；
  - 单国不确定性用配对地块 bootstrap（2,000 次）。
- **主要问题 1（OA，每种特征分别判定）**：类别构成部分在跨境损失中占多少？
  - "成立"：合并比例 ≥30% 且 95% CI 下限 ≥15%；
  - "方向性支持"：只有点估计 ≥30%；
  - "不成立"：点估计 <30%。
- **主要问题 2**：AE 与 S2 在"域残差"上是否不同？
  - 分别在 OA 链与 ba_ge30 链上比较，单位为 pp；
  - 判定为"有差异"：11 国平均差 ≥1 pp，Wilcoxon p < 0.05，并报告同向国家数。

## 次要问题（描述性）

1. **事后修正的 2×2 分解**：用 L0、LS、PO、W0、WPO 与 W-nat 做两条路径的分解，给出 Shapley 值和交互项。若 |交互项| ≥ 0.5×|总损失|，就标注"事后修正不可加"。
2. **"先验修正降低平衡精度"的检验**：ba(PO) − ba(LS) 与 ba(WPO) − ba(W0)，报告有多少国家同向。
3. **无标签与少标签的先验估计**（按信息条件分组：无信息 / 作物清单 / k 个标签 / 官方比例）：
   - 方法：PEM、PEM∘LS、PEM_bcts（在 L-cal 的外国校准集上拟合 BCTS 后做 EM）、PK50 与 PK200（Laplace +1 与 +0.5，另有只在类别集合内平滑的版本），以及 BBSE 作为敏感性分析；
   - 报告恢复率（合并）、π̂ 的 L1 误差、EM 迭代次数与是否收敛。
4. **BIAS_ORACLE**：在 LOCO 的 pool 预测上，用 pool 标签拟合 1 个温度和 10 个偏置，作为"只调整决策层能挽回多少"的上界。它用了大量目标国标签，需要注明。
5. **按类归因**：ΔOA = Σ_c π_test(c)·Δrecall_c。类别分为三组：
   - 同质：maize、potatoes、strawberries；
   - 异质：other_crops、orchards、vegetables；
   - 其余：grassland、winter_cereals、root_crops、tree_wood_forest。
6. **描述量相关**：类别构成部分（pp）与 JS(π_T, 均匀分布) 的相关为主，与 class_js 的相关为辅；域残差与细类构成 JS 的相关。
7. **敏感性分析**：
   - 空间分块版本（W0-sp、Wnat-sp，在空间分块 test 上重算全部链；LOCO 系列已保存 T 全部地块的预测，可直接复用）；
   - 去掉 RO、LV；
   - 去掉 other_crops 后的 ba_ge30；
   - 类别集合阈值：pool 中少于 20 个地块的类视为不存在。
8. **校准诊断**：
   - LOCO 与 W0 的隐含先验、ECE；其中 W0 只在 p_va 上计算；
   - 各模型的 best_iteration；
   - 若 L-cal 与原 LOCO 预测的最大差 ≥1e-6，所有由 LOCO 派生的量改用 L-cal。
