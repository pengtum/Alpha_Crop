- 来源：草稿 `ANALYSIS_PLAN_guidance_DRAFT.md` 加上三份独立审查的汇总 `GUIDANCE_DESIGN_REVIEW.md`。各项选择的理由和判定规则的模拟都在汇总文件里，这里只写要执行的内容。

## 1. 研究问题与估计量

**问题**（作者确定）：用地理嵌入（AlphaEarth，AE）作为指导信息来选择目标国要标注的地块，是否比用传统遥感影像特征（Sentinel-2 手工特征，S2）更可靠？

**核心操作**：同一单元、同一方法、同一种子，只替换"指导数据"。指导数据包括：
- **几何**：选样方法看到的特征空间，放在 ctx.T_ae 槽；
- **预测**：外国模型对目标候选池的校准概率，放在 ctx.P_T。

ctx 中其他与指导有关的字段一律置 None（T_s2、F_s2、T_xy、T_nuts3、F_country、P_T_loco、dom、P_F_oof），F_ae 只在 kcenter_foreign 条件下填入。

**单元级对比**：Δ = 精度(方法, AE 指导) − 精度(方法, S2 指导)。在同一单元、同一分类器、同一 k 下配对。

**E1（主要估计量，只用几何的通路）**：
- 国家 c 的值：4 个几何方法 × 2 种分类器 × 2 档 k × 4 个单元上 Δ 的等权平均；
- θ_E1：11 国国家值的均值。

**E2（次要，门控）**：完整替换。国家值 = 三条通路（几何、预测、几何+预测）各自国家均值的等权平均，每条 1/3。几何通路用全部 4 个单元，其余两条用 2 个单元。

**γ（次要）**：同源交互 = [Δ | AE 分类器 − Δ | S2 分类器] / 2，按 E1 方法取国家均值后再取均值。

**说明**：
- 方法作固定效应，估计量就是"这几个预先指定方法的等权平均"。
- srs 与指导无关（Δ≡0），不进入任何平均。

## 2. 指导条件

| 条件 | 几何（T_ae 槽） | 预测（P_T） | 方法 | 单元 | 层级 |
|---|---|---|---|---|---|
| AE | AE 稳健 PCA（第 3 节） | P_T_ae | 全部 8 个 | 几何 44，其余 22 | 1 |
| S2 | S2 稳健 PCA | P_T_s2 | 全部 8 个 | 几何 44，其余 22 | 1 |
| XY | 居中的公里坐标（2 列） | None | lpm2_nogeo、kcenter | 22 | 2 |
| S2XY | [part(S2 稳健 PCA 前 d 维), 2·xy 标准化]，以 d+2 调用 | None | lpm2_nogeo、kcenter | 22 | 2 |
| ORACLE | 交叉拟合 LDA 的类别判别分数（见下） | 交叉拟合的目标国模型 | lpm2_nogeo、typiclust、margin | 22 | 2 |
| AEg_S2p / S2g_AEp | 交叉 | 交叉 | gist_margin、badge_c | 22 | 3 |
| RAWZ_AE / RAWZ_S2 | 阶段 A 的原始 z + PCA | None | 4 个几何方法，只用 k=50 | 22 | 3 |
| NATIVE_AE / NATIVE_S2 | 见第 3 节 | None | lpm2_nogeo、typiclust，只用 k=50 | 22 | 3 |

**S2XY 的构造**：
- 列组成：S2 部分 = part(S2 稳健 PCA 的前 d 维)，即缩放到总方差为 d；坐标 = 居中、缩放到总方差为 2 后乘 geo_w=2。
- 调用方法时传入 d+2，所以 X_of 只做整体缩放，不会截掉坐标列。
- 坐标方差份额 = 8/(d+8)。geo_w=2 按阶段 A 的约定固定，不按数据调。

**ORACLE 指导**：阳性对照，只在重复 0 的 22 个单元上做。
- 在候选池内分 5 折交叉拟合，每个地块的指导值都来自不含它的 4 折。
- 预测：LightGBM（AE⊕S2 原始特征，300 棵树，按池频率计算类别权重），用袋外概率按 NLL 拟合标量温度。
- 几何：在同样 4 折上拟合 LDA（输入为 AE⊕S2 稳健特征，即 z 截断到 ±5），取对留出折的 decision_function。它有 C 列，每列对应一个类别，所以不同折的坐标含义一致；LDA 的 transform 坐标各折不同，不能跨折比较距离。再对这 C 列做同一稳健预处理（z 截断，不做 PCA）。
- 测试集地块不参与。

## 3. 几何空间预处理

**主分析**：函数 `preprocess_guidance(X_raw, clip=5)`，AE 与 S2 调用同一个函数，函数内没有按特征名分支的逻辑。
- 按外国 ∪ 目标（候选 + 测试）的均值与标准差做 z 标准化；
- 截断到 ±5；
- 在外国 ∪ 目标上拟合 PCA 到 32 维；
- 只用特征，不用标签。

**RAWZ（层级 3）**：阶段 A 的做法，z 标准化后直接 PCA，不截断。

**NATIVE（层级 3）**：
- AE：64 个 `_mean` 列，行向量 L2 单位化后 PCA 32 维；
- S2：84 个 `_mean` 列，走稳健 z（截断 ±5）后 PCA 32 维。

| 只用预测 | margin | 单轮 | 22 |

**kherding 保留**：阶段 A 日志中 kherding 选样耗时（PT 的 8 行）中位数为 4 秒，低于替换阈值 120 秒。冻结前只读了耗时行。

**badge_c**（G 专用，偏离阶段 A）：h = X_of(ctx,'ae',32) 减去候选池均值，其余与 badge 相同。原因是 BADGE 对 T 的整体平移不是不变的，而 PCA 原点相对候选池的偏移在 AE 与 S2 之间不同。

## 5. 单元、划分与预算

**国家与单元**：
- 11 国：AT、BE、DE、EE、LT、LV、PT、RO、SE、SI、SK，全部作确认国。
- 划分 {0, 1}（空间 10 km 格网，30% 测试，1 km 缓冲），构造与阶段 A 逐位一致。
- 重复 {0, 1}：候选池为从缓冲后候选集中抽 30,000 个，同阶段 A。
- 外国池：每个其他国家抽 5,000 个，同阶段 A。
- 选样种子与 LightGBM 种子都取 1000·split + rep，不依赖条件名、方法名或分类器。

**预算**：
- 主分析 k ∈ {50, 200}，两档合并。
- SRS 另跑 k=100 与 400；k=0 取阶段 0 的外国全量模型。四档共同组成 SRS 学习曲线，用来换算标签当量。
- 层级 3 另有 k=1000：SRS、lpm2_nogeo、typiclust，只用 AE 与 S2 指导。

## 6. 训练

**分类器**：LightGBM，分 S2 特征与 AE 特征两种，同一选样、同一种子各训练一次。
- 层级 3 另加 AE⊕S2 融合分类器（E1 方法，k=50，22 个单元）。

**训练设置**：
- 固定 300 棵树，参数同阶段 A；
- 类别权重只按外国频率计算，外国与目标样本共用；
- 目标样本权重 r=50；
- 训练集 = 外国池 + 所选的 k 个目标地块。

**缓存与稳健性**：
- 同一 (单元, 分类器, k, 选样哈希) 只训练一次，结果在各条件间复用。
- 同一模型在第 200、250、300 轮对测试集预测（num_iteration），作为预注册的稳健性分析。

**阶段 0**：每个 (国家, 划分) 一次，AE 与 S2 调用同一函数，唯一差别是特征矩阵。
- 外国全量模型：300 棵树，种子 0，给出对目标（候选 + 测试）的概率。
- 温度：外国 10 国分 5 组（每组 2 国），做分组留出。分组由 (国家, 划分) 的哈希固定，AE 与 S2 共用。在袋外概率上按 NLL 拟合标量温度，边界 (0.05, 20)。
- 保存：两种特征的校准概率、温度、外国袋外概率、ECE 与 NLL；以及 E_far 掩码（见第 7 节）。

## 7. 指标

**主要指标**：ba_ge30（测试集中 ≥30 个地块的类的平均召回），不做先验处理（P0）。

**OA**（P0）：H2 的门控非劣效检验，界值 −0.5 pp。

**P1 / P2**：只用于机制拆分。
- P1 = 设计先验（有包含概率时用 Hájek，否则用测试集上零标签 EM）；
- P2 = 候选池真实先验。
- 拆分方式：Δ(P0) − Δ(P2) 为类别构成与先验通道，Δ(P2) 为条件信息。

**E_far**：在每种划分内，取到"完整缓冲候选集"最近距离最远的三分之一测试地块。掩码只生成一次，所有条件与方法共用。

**中介变量**（分析时计算，不需训练）：
- AE 与 S2 选样的 Jaccard 重合度；
- 已选点最近邻距离的中位数；
- 测试集中离最近已选点 ≤5 km 的比例；
- "最远 1%"离群点比例；
- 所选样本类别构成与池先验的 L1 距离、覆盖类数；
- 在两种分类器特征空间中，所选样本与池的 MMD；
- 外国模型质量：log-loss、ECE、margin 识别误判的 AUROC、argmax 先验的 L1 误差。

## 8. 推断与判定

**推断**：以 11 个国家的国家值做单样本 t 检验（df=10），给出 95% 与 90% CI。

**SESOI**：0.3 pp。它是等价界和功效目标，不是点估计的门槛。

| 判定 | 条件（θ_E1，ba_ge30，P0） |
|---|---|
| AE 更好 | 95% CI 下界 > 0 |
| ……但实际等价 | 同时 90% CI 上界 < 0.3，措辞为"统计上略好，但优势小于 0.3 pp" |
| 等价 | 90% CI ⊂ (−0.3, +0.3)（TOST），且 95% CI 含 0 |
| S2 更好 | 95% CI 上界 < 0 |
| 不确定 | 其余情况：写成"效应被限定在 [L, U] pp，约合 x–y 个随机标签" |

**固定顺序门控**，每步 α=0.05：
- H1：θ_E1 ≠ 0，方向决定结论。
- 若 H1 判 AE 更好，依次检验：H2（E1 的 OA 非劣效，下界 > −0.5）→ H3（θ_E2 > 0）→ H4（R1：AE 的下行风险更低）。
- 若 H1 判 S2 更好，按对称方式处理。

**可靠性指标**：
- **R0（主要，估计量）**：国家层面 Δ_E1 的 80% 预测区间。τ² 用 REML 估计，均值的标准误用 HKSJ；国家内方差取合并值。PI = μ̂ ± t_{0.90, 9}·√(τ̂² + SE²)。
- **R1（门控 H4）**：
  - 对每个国家和每种指导，计算 E1 方法的"方法 − SRS < −0.5 pp"单元所占比例；
  - 11 国的 AE − S2 配对差做 t 检验，Wilcoxon 作敏感性。
- **R2（描述）**：国家内 log(SD_AE / SD_S2) 的跨国均值与 t 区间。
- **R3（描述）**：胜率 P(方法 < SRS)；Δ>0 的国家数。

**"更可靠"的表述**：
- H1 判 AE 更好且 H4 成立：写"平均与下行风险都更可靠"；
- R1 显著更差：写"平均更好但不更可靠"。

**次要结果**（不校正，标明"次要"）：
- γ；各通路的 θ；各 k 的 θ；
- XY 与 S2XY 的对比：AE − S2XY、AE − XY、S2XY − S2；
- 神谕提升空间 H = θ_ORACLE − θ_S2，以及 AE 所占比例 ρ = θ_AE−S2 / H（只在 H 的 95% CI 下界 > 0 时报告）；
- P2 拆分；E_far；
- 逐方法结果：做部分合并，给出收缩估计，不下显著性结论。

**标签当量**：每个国家、每种分类器上，把 SRS 学习曲线（k = 0/50/100/200/400）做单调插值，把 Δ 换算成随机标签数。

**敏感性分析**：
- 混合模型；wild cluster bootstrap（Webb 权重）；
- 国家子集：去掉检验 2 的 4 国（剩 7 国）、去掉 RO、去掉开发国 PT/BE/SI；
- 第 200、250 轮的结果。若 E1 在 250 与 300 轮下符号相反，结论标注为"依赖训练容量"；
- 层级 3 的条件。

## 9. 运行顺序与削减

**运行顺序**：阶段 0（22 个）→ 11 国"划分 0 重复 0"的层级 1 → "划分 1 重复 0" → "划分 0 重复 1"（只跑 E1、SRS 与 SRS 学习曲线）→ "划分 1 重复 1" → 层级 2（ORACLE 交叉拟合 → XY、S2XY、ORACLE 选样）→ 层级 3（顺序为 RAWZ、通路交叉、NATIVE、融合分类器、kcenter_foreign、k=1000）。

**超时削减顺序**：
1. 温度留出从 5 组改为 3 组；
2. ORACLE 去掉 typiclust；
3. XY 与 S2XY 只做 k=50。

不削减：两种分类器、E1 的 4 个方法 × 44 个单元、SRS、300 棵树。

**结论时点**：层级 1 与层级 2 完成后才写结论。
