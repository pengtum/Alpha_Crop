## A. 有偏初始样本下的先验估计：只走先验（OA）通道

**要回答的问题：** 目标国已有按簇采集、空间有偏的初始样本 S0 时：
1. 它把类别先验估偏了多少？
2. 补采能否纠正？
3. 先验该用哪些标签来估？
4. 在两种成本口径下，补采该扩大原调查区，还是全国分散？

**只能回答的范围：** 本部分只涉及"冻结外国模型 + 先验修正（PK）"这一用法。S0 与补采样本用于重训之后对平衡精度（BA，域残差）的作用，要等确认运行。

### A1 单元与底座

- **单元**：11 国 × 划分 {0, 1}，共 22 个。每个单元、每种场景抽 R = 20 次，种子为 md5(f'step0A_{国家}_{划分}_{场景}_{n0}_{r}') 的前 8 位十六进制。
- **抽样框**：该单元的全部缓冲候选地块 `cand`（stage0 文件），不用 3 万池。
- **底座概率**：`P_T_{f}` 的测试行（温度校准，float32；即 D1 的底座），f ∈ {ae, s2}。另用 `P0test_{f}_i300`（G 中 foreign_only 行的底座）只重算"无修正"与"真实先验"两行，用于与 G 数字对账。
- **训练先验 π_train**：与 `guidance_G.run_unit` 中 `pi_train_of([], 0)` 相同，即外国池标签按 `class_weights_from(y_foreign)` 加权后的类别分布。
- **先验修正**：`check3_priors.reweight(P, π_new, π_train)`。
- **评估类**：`big` 取测试集中 ≥ 30 个地块的类，与 G 相同。
- **指标**：测试集 OA 与 ba_ge30。

### A2 格与调查区

- **格**：候选地块按 `km_xy(lon, lat, lat0)` 划 10 km 格，与 `make_split` 相同。
- **调查区**：对"候选地块数 ≥ 10 的格"的质心做 KMeans（8 个区，n_init = 10，random_state = 0），每个单元只拟合一次。其余格按质心最近原则归区。

### A3 初始样本 S0

**n0 与每簇地块数 M：** n0 ∈ {100, 500, 2000}，对应 M ∈ {10, 20, 25}，簇数为 n0 / M，即 10 / 25 / 80 个。合格格是指候选地块数 ≥ M 的格。

**S0 的三种类型：**
- **clus**（Betti 式）：
  1. 按各区候选地块数 PPS 不放回，先抽 2 个区。
  2. 如果所选区内合格格少于"簇数 + 20"，再按 PPS 追加一个区，直到满足。记录用了几个区。
  3. 在所选区的合格格中，按格内候选地块数 PPS 不放回抽簇（Efraimidis–Spirakis）。
  4. 每格简单随机抽 M 个地块。
- **rand**：从抽样框简单随机抽 n0 个地块。
- **none**：n0 = 0，只作参照。

**记录：** S0 类别构成与抽样框类别构成的 L1 距离（偏差强度），以及所用区数。

### A4 补采 S1

S1 与 S0 不重叠。

**口径 1：标签预算 k（每地块等成本）。** k ∈ {50, 200}。

| 臂 | 做法 | 适用的 S0 |
|---|---|---|
| **SRS** | 从抽样框中除 S0 以外的地块简单随机抽 k 个 | 所有 S0 |
| **EXT-p** | 只从 S0 所在区内除 S0 以外的地块简单随机抽 k 个 | 只用于 clus |
| **Betti-Admin(S0)** | 见下文 | 所有 S0 |
| **Betti-Img-ae(S0)**、**Betti-Img-s2(S0)** | 见下文 | 所有 S0 |

- Betti-Admin(S0) 的分配：
  - 组 = 8 个调查区；γ_g 为该区在抽样框中的占比；n⁰_g 为 S0 落在该区的个数。
  - 贪心分配：每步把一个名额给边际增益 γ_g[(n⁰_g + n_g + 1)^(−½) − (n⁰_g + n_g + 2)^(−½)] 最大、且未超过容量的组。容量为该组中除 S0 以外的地块数。平局取编号小的组。
  - 组内简单随机抽取。
  - 这对应 Betti 的 Admin-Rep 加上已有样本的情形。
- Betti-Img-ae(S0)、Betti-Img-s2(S0)：
  - 组 = 抽样框在 `G_{f}` 几何（候选行）上做 KMeans（8 组，n_init = 10，random_state = 0）得到的组。
  - 其余同 Betti-Admin(S0)。

**口径 2：调查成本预算 B（按簇）。** 只用于 clus 型 S0。
- B = 20 个成本单位，每簇 M = 10 个地块。
- 可用簇：候选地块数 ≥ 10、且不是 S0 所用格的格。
- 成本：c1 = 1。

| 臂 | 做法 |
|---|---|
| **EXT** | 在 S0 所在区内，按地块数 PPS 不放回抽 20 个簇，得 200 个标签 |
| **SPR** | c2 = 2。对全国可用簇做一次 PPS 加权随机排序（Efraimidis–Spirakis），按序加入：区内的簇记 c1，区外的记 c2。遇到剩余预算付不起的簇时停止。记录所得标签数 |
| **SPR=** | c2 = 1。取同一排序的前 20 个簇，得 200 个标签。SPR 是 SPR= 的前缀 |

### A5 先验估计量

记平滑函数 lap(y) = `check3_priors.laplace_prior(y, 10, alpha=1)`，与 PK50 相同。

| 估计量 | 定义 |
|---|---|
| **E_S0** | lap(S0 的标签)，只用已有样本 |
| **E_pool** | lap(S0 ∪ S1 的标签)，简单合并 |
| **E_S1** | 只用补采样本。SRS、EXT-p、EXT、SPR、SPR= 用 lap(S1)（PPS 格 + 固定 M，近似自加权）。Betti 分配用 Hájek：组 g 中每个样本的权重为 N_g / n_g（N_g 为组中除 S0 外的地块数）；平滑后为 p̂_c = (n·h_c + 1)/(n + 10)，h_c 为 Hájek 比例，n = \|S1\| |
| **E_EM** | 零标签 EM（`check3_priors.em_prior`），参照 |
| **E_none** | 不做修正，参照 |
| **E_oracle** | 测试集真实类别比例，作上界 |

### A6 指标与汇总

**每次抽样记录：**
- 修正后的测试集 OA 与 ba_ge30；
- 先验 L1：‖p̂ − π_test‖₁；
- S0 的偏差强度与所得标签数。

**汇总方式：**
- 国家值 = 两个划分 × 20 次抽样的平均。
- 报 11 国与去掉 RO、PT 的 9 国：均值、95% CI（t 分布，df = 10 或 8）、>0 的国家数。
- 恢复率 = (OA_E − OA_none) / (OA_oracle − OA_none)，只报国家均值之比，不报逐单元的比值。

**要报告的对比（全部描述性，不做判定）：**
- **A-c1 初始样本的偏差：** 在每个 n0 下，比较 E_S0 在 clus 与 rand 下的先验 L1 和 OA 恢复率。
- **A-c2 先验用哪些标签估**（clus 型 S0，k = 200，SRS 补采）：比较 OA(E_S1) − OA(E_pool) 与 OA(E_S1) − OA(E_S0)，并按 n0 分别报告。rand 型 S0 下做同样比较，作对照。
- **A-c3 成本口径下补采放在哪里**（clus，成本预算 B）：在 E_pool 与 E_S1 下，比较 EXT、SPR、SPR= 三臂，报 OA、先验 L1 与所得标签数。
- **A-c4 Betti 分配与 SRS 的比较**（E_S1，k ∈ {50, 200}）：比较三种 Betti 分配与 SRS，并报 AE 分组与 S2 分组之差。
- **A-c5 各估计量下 BA 的代价：** 预期为负，是 BA 定义的推论，不作为发现。
- **A-c6 n0 的趋势：** 从 100 到 2000，E_pool 相对 E_S1 的差距如何变化。

**对账：** 在 P0test_i300 底座上，把 E_none、E_oracle 的 OA 与 G 的 foreign_only 行（oa、oa_P2）核对。P2 用的是候选池先验，不是测试先验；如果不同，写明差异来源。

## B. 工作点对齐回溯：为确认运行的主指标做可行性与功效估计

**要回答的问题：**
1. 把"在同一 OA 窗口内比较平衡精度"的主指标 FA 作为确认运行的主指标，是否可行？
2. 各臂在 OA 窗口内能否达到？
3. 用国家为推断单位时，功效有多大？
4. 这个包络有多大的乐观偏差？

### B1 单元与臂

**单元：** G 的 44 个单元（11 国 × 划分 × 重复），分类器特征 f ∈ {ae, s2}。

| 臂 | 概率来源 |
|---|---|
| **Z0**（零标签） | `P_T_{f}` 测试行 |
| **RT-k**（并入重训，LightGBM） | G 的 SRS 选样对应的 `probs/{单元}_{f}_k{k}_{hash}.npz` 中的 i300，k ∈ {50, 200, 400} |
| **HD-k**（BCTS 决策头） | 在 G 同一批 SRS 选样的候选行 `P_T_{f}` 上拟合 BCTS，拟合方法与 D1 的 `head_eval` 相同，λ = 0.1、类均衡权重；再应用到测试行。k ∈ {50, 200, 400} |
| **RT-k（LR、MLP）**（次要） | `guidance_G_ml/probs/{lr,mlp}` 中 SRS k = 200 与 k = 0 的 P |

### B2 工作点族与 FA

- **工作点族：** 对每个臂的测试概率 P，令 ℓ = log P − τ·log π̂，其中 π̂ 是该臂在测试集上的平均预测概率（不用标签）。τ 网格为 −0.5 到 2.0，步长 0.05。
- **每个 τ 下**算测试集 OA 与 ba_ge30，得到该臂在 BA–OA 平面上的一条曲线。
- **锚点：** OA★ = Z0 在 τ = 0 时的 OA，每个单元、每种特征各一个。
- **窗口与 FA：**
  - OA 窗口 W = [OA★ − 4, OA★]，步长 0.1。
  - 对窗口中每个 o，取该臂曲线上 OA = o 处 BA 的上包络（相邻 τ 点之间线性插值；多段都经过 o 时取最大）。
  - FA 为这些 BA 的平均。
- **可达：** 该臂的 OA 范围覆盖 W 的比例。
  - 覆盖不足 100% 时，FA 只在可达部分计算，并标"部分可达"。
  - 覆盖率 < 50% 时，FA 记为缺失。
- **零标签包络加 EM 点：** Z0 包络另加入 EM 修正后的点（`em_prior`，以及 EM 修正后再走同一 τ 族）。取两条曲线的上包络，记为 Z0+。CORAL 需要重训，第 0 步不做，只注明。

### B3 估计量

每个单元计算以下差值，再平均到国家：
- ΔFA(RT-k) = FA(RT-k) − FA(Z0+)；
- ΔFA(HD-k) = FA(HD-k) − FA(Z0+)；
- FA(RT-k) − FA(HD-k)。

另外：
- 同时报 τ = 0.5 这一可部署点的 BA 与 OA 差。
- 报 11 国与 9 国：均值、95% CI、>0 的国家数。
- 报各臂的可达率分布，与"部分可达"或缺失的单元数。

### B4 功效

- 取国家层 ΔFA 的标准差（9 国与 11 国），给出确认运行中 95% CI 的预期半宽，以及 80% 功效下的最小可检出效应。
- 确认运行只有 22 个单元、只用 rep0。按单元数调整时，写明所作的假设。

### B5 包络偏差检查（split-half）

- 把每个单元的测试集按种子 md5(f'step0B_{单元}') 随机分成两半 a、b。
- 在 a 上求曲线，对窗口中每个 o 找到在 a 上达到 OA = o 的 τ(o)；把 τ(o) 用到 b，算 b 上的 BA。
- 与直接在 b 上求包络得到的 FA_b 比较，报两者之差的均值与分布。这是"用测试标签画包络"的乐观偏差估计。
- 两个方向（a→b 与 b→a）都做，取平均。
