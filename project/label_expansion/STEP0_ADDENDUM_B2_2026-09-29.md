# 第 0 步补遗 B2：同 OA 下标签增益的分解（先验信息 vs 其余）

2026-09-29。写于看到第 0 步 B 部分结果之后（因此属事后分析），但在做本补遗任何计算之前。sha256 记入 `plan_hashes.txt`。全部 C 级、描述性；不训练；只读已存概率与 G 的选样。

## 动机

第 0 步 B：同一 OA 窗口内，LightGBM 并入重训相对零标签工作点族的 ΔFA(RT200) = +2.10 [+1.40, +2.81]（9 国，9/9）。零标签对照不知道目标国的类别比例，而 200 个标签同时提供了类别比例。本补遗把 ΔFA(RT-k) 分解为两部分：
- (i) 同一批标签提供的"类别先验信息"能解释多少；
- (ii) 扣掉先验信息后，重训还多出多少。

## 设定（除下列改动外，与 STEP0_SPEC B 部分相同）

**单元与特征：** G 的 44 个单元，特征 f ∈ {ae, s2}，只用 LightGBM。k ∈ {50, 200, 400}。

**τ 网格：** 改为 −2.0 到 2.0，步长 0.05，所有臂一律用这个网格。这是审计指出的 HD 曲线在 −0.5 处被截断的修正。τ 族、π̂（该臂测试集平均预测）、log 取法、OA★、窗口、FA、可达与缺失规则，都与第 0 步 B 的主实现 `step0B.py` 相同。

**零标签参照：** 主参照改为 Z0（`P_T` 测试行的 τ 族，不含 EM 点）。审计显示 EM 在 P_T 上几乎不起作用，而且 RO 上对 log 取法敏感。Z0+ 另外列出。

**臂：**
- **Z0：** 如上。
- **PK-k：** 用与 RT-k 相同的那批 G SRS 选样的标签（rows_t1 中 method=srs、cond=none、对应 k 与 clf 的 sel_hash），计算 p̂ = `check3_priors.laplace_prior(y_sel, 10, alpha=1)`。先把 `P_T` 测试行用 `check3_priors.reweight(P, p̂, π_train)` 重加权（π_train 与 STEP0_SPEC A1 相同），再走 τ 族。
- **PKo：** 同上，但 p̂ 取测试集真实类别比例。这是"先验信息"的上界，与标签数无关。
- **RT-k：** 同第 0 步 B，在新网格上重算。
- **HD-k：** 同第 0 步 B，在新网格上重算。

## 估计量

每个单元计算，再平均到国家：
- **先验信息的价值：** A_k = FA(PK-k) − FA(Z0)；A_o = FA(PKo) − FA(Z0)。
- **扣掉先验信息后重训多出的部分：** R_k = FA(RT-k) − FA(PK-k)。
- **ΔFA(RT-k) = A_k + R_k。** 报告 A_k 占 ΔFA(RT-k) 的比例（只报国家均值之比，不推断）。
- **扣掉先验后决策头多出的部分：** H_k = FA(HD-k) − FA(PK-k)。
- **对照：** 用新网格重算的 ΔFA(RT-k)、ΔFA(HD-k)、FA(RT-k) − FA(HD-k)，并与第 0 步 B 的旧网格结果并列。
- **可达率：** 各臂在新网格下的全可达、部分可达、缺失单元数。

**汇报范围：**
- 11 国与 9 国（去掉 RO、PT）；9 国为主。
- 以两特征国家值的平均为主，ae、s2 分列。
- 均值、95% t CI、>0 的国家数。

## 读法（事先写定）

对 k = 200、9 国：
- **R_200 的 95% CI 下界 > 0：** 扣掉先验信息后，重训仍把前沿外推。可以写成"标签补上了一部分域残差"（C 级）。
- **R_200 的 95% CI 覆盖 0，且 A_200 占 ΔFA(RT200) 的比例 ≥ 70%：** 同 OA 下的增益主要来自类别先验信息，"标签主要提供类别比例"。
- **其余情况：** 不确定，两者都有贡献。
