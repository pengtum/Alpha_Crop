RSE 新增描述性分析与图件（2026-10-07）

目标与图件契约
1. 数据分布图：空间覆盖、国家内类别比例、全体类别长尾。全部配对地块，不作类别平衡抽样。
2. 零标签精度图：同一正式空间测试集上的 AE/S2 OA、BA 配对，并列原登记的 matched-OA 差。
3. 混淆矩阵：主图对有资格的半区先平均、再按国家等权；附属图集逐国合并两半计数，显示所有类及支持数。
4. 两两迁移：修复数据的 110 个有向源国→目标国组合，每个组合同时展示 AE、S2 与差值。

Python/matplotlib 绘图；定量多面板。原样调用父目录 nstyle，不改冻结文件。
四张新图导出 SVG、PDF、600 dpi TIFF、300 dpi PNG；逐国混淆矩阵导出 11 页 PDF 和逐页 PNG。
Arial 必须可用；最小字号 5.5 pt。颜色语义、线宽、标记和面板编号沿用原样式。
空间地图用 EPSG:3035。底图复用既有边界。

依次运行（在项目环境中）：
python -B prep_diagnostics.py
python -B plot_diagnostics.py
python -B package_diagnostics.py

prep_diagnostics 只读既有地块、正式概率、划分与两两迁移结果，不训练模型。
输出源数据独立保存；不会改写原 source_data、冻结分析或正式运行目录。
正式预测标签顺序与缓存逐行核对；44 个单元×特征的 OA/BA 与原分析逐值核对，容差 1e-9 pp。
测试半区必须无重复；两两迁移目标样本数必须与当前数据逐国一致。
audit.json 保存输入哈希与复算结果；style_qa.json 保存字号与字体检查。

统计解释
新增数据分布与精度诊断均为事后描述性分析，不新增确认性检验。
正式零标签精度按两半平均，再按国家等权；BA 沿用各半区冻结类别集合。
混淆主图按真实类别的可用国家平均，不能从对角线反推出论文国家平均 BA。
逐国矩阵合并计数，含稀有类，并标注支持数。无观察的类显示灰色，不填零。
单源迁移使用不同训练量、随机源内划分和全目标评估，不能与正式多源空间评估直接相减。
没有标签不等于没有该作物；RO 是粗粒度土地覆盖，LT/LV 的标签支持还受配对特征过滤影响。
本次不使用 NC 正式结果来替换 RSE 的冻结指标或主检验。
