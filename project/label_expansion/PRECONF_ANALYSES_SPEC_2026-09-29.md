**定位**
- 所有分析都是事后分析，只用已复用的 G s0/s1 与检验 3 测试集，C 级、描述性。结果只用于写确认运行的登记方案，以及正文的描述性内容。
- 不训练任何作物分类器，只读已存的概率与几何。AE6 中的近邻计算不涉及训练。
- 候选标签与外国标签只用于估比例、拟合头、做类条件距离；测试标签只用于评估，不用来选择任何参数。唯一例外是 L4，它只用 k 个候选标签选 τ。

**通用口径（未另外说明时）**
- τ 族、上包络插值、FA、可达与缺失规则，都与第 0 步补遗 B2 的 `step0B2.py` 相同：τ ∈ [−2, 2]，步长 0.05；π̂ 取该臂测试集平均预测；log 为精确 log。
- 零标签参照为 Z0，不含 EM 点。
- 窗口：W4 = [锚点 − 4, 锚点]。
- 国家值为该国单元的平均。报告 11 国与 9 国（去掉 RO、PT），给出均值、95% t CI、>0 的国家数；以两种特征国家值的平均为主，ae、s2 分列。

**输出目录**：`~/AlphaCrops_local/verify/preconf/`，下设 `ae/`、`label/`。线程 ≤ 2，不在项目目录生成 `__pycache__`，不改项目目录与 `results/`。

## 一、AE 线

### AE1 同 OA 下 AE−S2 前沿差：跨臂、跨学习器

对每个单元：
1. 两种特征各用自己的臂曲线。
2. 锚点取两种特征零标签参照在 τ = 0 时 OA 的较小者，即 min(OA★_ae, OA★_s2)。
3. 在窗口内逐点计算 BA_ae(o) − BA_s2(o)，再取平均，记为 D_arm。
4. 两条曲线在窗口内共同可达的比例不足 50% 时，记为缺失。

**LightGBM：** 臂取 Z0、PK200、RT200、HD200，直接读补遗 B2 的 `curves_B2.csv`。零标签 Z0 的 D 已由 AE–S2 整合评估算出，本项复算，作为对账。

**LR、MLP、RF：**
- 臂取 k = 0 与 SRS k = 200 的已存概率（`results/guidance_G_ml/probs/{lr,mlp,rf}`）。
- 锚点取本学习器 k = 0 在 τ = 0 时两种特征 OA 的较小者。
- RF 的 argmax 并列按原样处理，并在输出中注明并列比例。

**另报：**
- 窗口宽度 2、4、8；锚点分别取 OA★_ae 与 OA★_s2 的版本。
- 可部署点 τ = 0.5 时 AE−S2 的 BA 与 OA。
- 44 个单元中，AE 在整个窗口占优的单元数与 S2 在整个窗口占优的单元数。

### AE2 国内与跨境：AE 的前沿优势是迁移中放大的，还是水平平移

**数据：** 检验 3 的已存测试概率（`results/check3/`）。划分为随机 70/30、无缓冲。测试标签按 `check3_decomposition.py` 与 `check3_priors.py` 的取法获得，实现时核对。

**对每个国家与特征，取两种模型的测试概率：**
- 国内模型：`within`；
- 跨境模型：`loco`，即只用外国数据；
- 设置：c300（固定 300 棵，与 G 一致）为主，早停为次。

**计算：**
1. 各自做 τ 族。
2. 国内与跨境分别按 AE1 的方法计算同 OA 下的 AE−S2，锚点为该模型两种特征 τ = 0 时 OA 的较小者，分别得到 D_dom 与 D_xb。
3. 报告 D_dom、D_xb，以及 D_xb − D_dom。
4. 同时报 τ = 0 的 AE−S2 作为对照。

**读法（描述）：**
- D_xb − D_dom 的 95% CI 下界 > 0：AE 的前沿优势在跨境时放大；
- CI 覆盖 0：没有检出放大，写成"AE 在国内与跨境都抬高前沿"；
- CI 上界 < 0：跨境时缩小。

### AE3 按类拆分

- **对象：** LightGBM 零标签 Z0。
- **取点：** 在窗口中点 o_mid = 锚点 − 2 处，两种特征各自取曲线上 OA = o_mid 的点。该点所在 τ 段与插值系数同上包络，逐类召回率按同一系数在相邻两个 τ 之间线性插值。
- **报告：** 每类召回的 AE−S2。先平均到国家（只计该国测试集中该类 ≥ 30 个地块的国家），再报均值与国家数。
- **对照：** τ = 0 的逐类差。

### AE4 地块大小

- **核面积：** π × 30² ≈ 2,827 m²。
- **分组：** 测试地块按面积 ÷ 核面积分为 5 组：<0.5、0.5–1、1–2、2–4、≥4。
- **每个单元、每组计算以下三项：**
  - 该组占测试地块的比例；
  - τ = 0 与 AE3 所取的同 OA 点（同一个 τ）上，组内 OA 的 AE−S2；
  - 组内平衡精度的 AE−S2。只计该单元该组中 ≥ 30 个地块的类；少于 2 个类时记缺失。
- **用途：** 描述 AE 的优势是否随地块变大而改变，用来检验"30 m 核混入邻田"这一说法。

### AE5 零标签 EM 的先验误差

- **对象：** LightGBM 的 P_T，两种特征。
- **计算：** 分别算 EM 估出的 π̂ 与测试集真实比例之间的 L1，比较 AE 与 S2，并按国家列出。
- **关联：** 与检验 3 中 EM 恢复率的差异对照（描述）。

### AE6 类条件分离：机制描述

- **几何：** stage0 的 `G_f`（候选行）与 `GF_f`（外国池），32 维，是两者的联合 PCA。
- **对每个目标国（划分 0）、每种特征、每个类 c**（目标候选与外国池中该类都 ≥ 100 个）：
  1. 各随机抽 min(500, n) 个。
  2. 对每个目标样本，在合并样本中找 10 个最近邻（欧氏距离，排除自身），计算其中外国样本所占的比例。
  3. 取平均，记为混合指数 M_c。0.5 附近表示两边充分混合，接近 0 表示两边分离。
  4. 种子为 md5(f'AE6_{国家}_{特征}_{类}') 的前 8 位十六进制。
- **类无关版本：** 不分类，全部样本各抽 2,000 个，计算 M_all。
- **报告：**
  - 每个国家中各类 M_c 的中位数，以及 M_all；
  - 两者的 AE−S2；
  - 与 AE1 中各国 Z0 的 D 做 Spearman 相关（n = 11，描述）。

### AE7 界值与功效

**界值：** 对补遗 B2 中 A_200、R_200、ΔFA(RT200) 的 AE−S2 交互量，给出 9 国与 11 国的 90% CI，以及按 ±1 pp 做 TOST 的 p 值；另报 L1 中 R*_200 的 AE−S2。

**功效：** 以只用 rep0 的单元计算国家层 SD，假设确认运行为 22 个单元（11 国 × 2 个半区），给出以下两项在 9 国与 11 国下的功效或 MDE80：
- H_R1：同 OA 下 AE−S2 > 0，单侧 α = 0.025；
- H_R2：交互量按 ±1 pp 做 TOST，α = 0.05。

## 二、标签线补充

### L1 重训后再按同一比例修正（审计 M1 指出的缺口）

- **做法：** 对 LightGBM 的 RT-k（k ∈ {50, 200, 400}），用同一批标签的 p̂_k（Laplace，α = 1）重加权，得到 RTPK-k。重加权相对的训练先验为该重训模型的实际训练先验，即与 `guidance_G.run_unit` 中 `pi_train_of(sel, R_MULT)` 相同。
- **估计量：**
  - R*_k = FA(RTPK-k) − FA(PK-k)，即重训在比例信息之外的增益，且两边都用了比例；
  - FA(RTPK-k) − FA(RT-k)；
  - 报可达率。
- **读法（描述，k = 200，9 国）：**
  - R*_200 的 95% CI 下界 > 0：重训在比例之外有增益；
  - 否则：未检出。

### L2 LR、MLP 下的同一分解

- **数据：** `results/guidance_G_ml/probs/{lr,mlp}` 中 k = 0 与 SRS k = 200 的概率。
- **做法：**
  - Z0 用本学习器 k = 0 的概率。
  - PK200：对本学习器 k = 0 的概率，用同一批 200 个标签的 p̂ 重加权；训练先验同 LightGBM 的外国池先验，因为训练权重规则相同。
  - RT200 与 RTPK200 同 L1。
  - 锚点取本学习器 Z0 在 τ = 0 的 OA。
- **报告：** A_200、R_200、R*_200、ΔFA(RT200)，9 国与 11 国。

### L3 窗口敏感性

对以下各量，窗口宽度分别取 2、4、8 重算：
- ΔFA(RT200)；
- A_200；
- R_200；
- R*_200（LightGBM）；
- AE1 中 Z0 与 RT200 的 D。

### L4 只用 k 个标签选 τ 的可部署规则

**规则（事先写定）：** 在 k 个 SRS 标签上计算各 τ 的 BA_k 与 OA_k，取在 OA_k(τ) ≥ OA_k(0) − 2 条件下使 BA_k 最大的 τ̂。

**适用的臂：**
- Z0、PK-k、HD-k 用这一规则：对 Z0 而言标签不参与拟合；对 PK 与 HD 而言标签参与了估计，属于样本内，要注明。
- RT-k 的标签在训练集中，不用这一规则，只报固定 τ ∈ {0, 0.25, 0.5}。

**报告：**
- 各臂在 τ̂ 下的测试集 BA 与 OA；
- 相对 Z0 在同一规则下的差值；
- k ∈ {50, 200, 400}。

### L5 只用目标池训练的模型（tgt300），同口径

- 如果 `verify/model_diag` 中存有 tgt300 的测试概率（只有划分 0），就计算 FA(tgt300) − FA(Z0)，与 ΔFA(RT-k) 放在同一口径下比较。
- 如果不存在，就写明"不可得"，只报已有的 τ = 0 差距，不另行训练。
